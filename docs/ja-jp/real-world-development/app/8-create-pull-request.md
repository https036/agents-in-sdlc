フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストは、ひとつのブランチに保存されています。これらをまとめてレビューし、プルリクエストを作成します。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスを任せます。

> [!NOTE]
> 通常は機能、指示の更新、スキルの更新、QA エージェントをいくつかの PR に分けます。ワークショップを簡潔にするため、フィルター機能と品質ワークフロー全体をひとつのセッションとブランチで進め、すべての作業をこの PR にまとめました。

このレッスンでは、次のことを行います。

- Agent Merge とは何か、マージのライフサイクルを自動化する方法を学びます。
- 機能の PR 全体と検証の根拠を確認します。
- レビュー後にのみ Agent Merge を許可し、PR がマージされたことを確認します。

## シナリオ

フィルター機能のワークフロー全体を通して、Copilot を使って機能を計画、実装、検証してきました。Tailspin Toys は、マージの許可を開発者の管理下に置きながら、残りの PR 作業を自動化したいと考えています。

## Agent Merge の概要

**Agent Merge** は、GitHub Copilot app でプルリクエストをマージするために必要な残りの作業を自動化します。有効にすると、app のセッションがプルリクエストを読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビュー コメントへの対応、必要に応じたリベースなど、マージを妨げる問題に対処します。GitHub が許可すると、プルリクエストをマージします。バックグラウンドで動作し、app を再起動しても継続し、プルリクエストがマージされると自動的に無効になります。

これまでは、自分で **Merge pull request** を選択していました。Agent Merge にその作業を任せることもできますが、コードの編集とマージには明示的な許可が必要です。マージ権限を与える前に、許可される操作と作業を確認してください。

## Agent Merge で PR を管理する

コードの作成とレビューが完了したら、Agent Merge に PR プロセスを任せましょう。

1. エージェント ピッカーから **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンの表示が **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択してプロセスを開始します。ドロップダウンから選択しただけでは開始しません。

Agent Merge のプロセスが開始され、次の処理を行います。

- タイトルと説明を付けてプルリクエストを作成します。
- issue からセッションを始めた場合は、PR 説明の本文に関連する issue を記載します。
- ターゲット ブランチに対してリベースするか、マージ競合に対処します。
- CI プロセスを監視し、すべてのチェックが成功することを確認します。
- ほかの開発者や Copilot code review からのフィードバックがないか PR を監視し、コメントを解決するために更新します。
- 必要に応じて、すべて成功した後に PR を自動マージします。

すべてのチェックが成功したら、Agent Merge に PR もマージさせましょう。

5. マージ権限を与える前に、PR の差分と検証の根拠を確認します。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. 次のプロンプトを使い、エージェントにマージを明示的に依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 進行状況を確認し、報告された問題に対処します。続行する前に、PR の状態が **Merged** であることを確認してください。マージ権限が有効になったことやエージェントが実行中であることは、マージの完了を意味しません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前に、これらの問題を解決してください。
