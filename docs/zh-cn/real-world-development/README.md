通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。你将反复规划变更、编写代码、测试行为、审查 pull request，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游众筹提供服务，并以开发者为主题。团队已经将待办工作整理为 GitHub issue，随时可以开始处理。其中既有筛选和分页等功能开发，也有无障碍和编码标准等质量改进。

## 选择工作环境

无论在哪里工作，都可以使用 GitHub Copilot。选择最适合你构建项目的环境。每个工作坊都有独立的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用 Canvas，以及管理 GitHub issue 和 pull request。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步智能体、引导其工作、监控进度，并审查它创建的 pull request。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可体验 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
